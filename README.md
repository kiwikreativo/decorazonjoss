# Decorazon Joss

Business website for **Decorazon Joss**, an event decoration company. Built with Astro to showcase their decoration styles and services and help clients get in touch for their events.

## ✨ Features

- 🎉 Showcase of event decoration styles and services
- 📱 Fully responsive design
- ⚡ Fast, static-first site built with Astro
- 📞 Contact section for client inquiries

## 🛠️ Tech Stack

- **[Astro](https://astro.build)** — site framework
- **TypeScript** — type-safe components
- **CSS** — styling

## 🚀 Getting Started

```bash
pnpm install
pnpm dev
```

Runs locally at `localhost:4321`.

## 📦 Available Scripts

| Command         | Action                          |
| --------------- | -------------------------------- |
| `pnpm dev`      | Start local dev server           |
| `pnpm build`    | Build for production             |
| `pnpm preview`  | Preview the production build     |
